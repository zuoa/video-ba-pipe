# 离线许可证与永久免费试用版

## 默认授权

系统未安装有效许可证时自动使用永久免费试用版：全库最多创建 1 个视频源和 3 个算法。已有付费许可证失效时，数据不会被删除；运行时固定选择 ID 最小且已启用、有活动工作流的视频源，并只允许 ID 最小的三个算法参与执行。

所有有效许可证同样严格执行签名额度。若安装额度更低的许可证，系统保留超额数据，并按视频源、算法 ID 从小到大确定可运行子集；超额资源立即停止运行，额度恢复后自动恢复。

删除资源使数量回到额度以内后，可以继续创建。安装或续期有效许可证后，worker 会在下一轮管理周期自动恢复原配置。

## 许可证格式

许可证是 UTF-8 编码的 compact JWS 文本，建议使用 `.license` 扩展名，最大 64 KiB。签名算法必须为 Ed25519：

```json
{
  "alg": "EdDSA",
  "kid": "vendor-v1"
}
```

Payload 示例：

```json
{
  "schema_version": 1,
  "license_id": "customer-a-2026-001",
  "customer": "客户 A",
  "node_id": "00:11:22:33:44:55",
  "iat": 1786896000,
  "nbf": 1786896000,
  "exp": 1818432000,
  "limits": {
    "video_sources": 16,
    "algorithms": 20
  }
}
```

`iat`、`nbf`、`exp` 均为 UTC Unix 秒。额度必须分别不小于免费版的 1 和 3。签发端必须严格生成上述字段，并使用与发行镜像公钥匹配的私钥签名。

## 公钥与安装

发行镜像必须将 `app/license_public_key.pem` 替换为厂商 Ed25519 公钥。也可在定制部署中设置 `LICENSE_PUBLIC_KEY_PATH` 指向镜像内的只读 PEM 文件；私钥禁止进入源码、镜像或客户设备。

管理员可在“系统设置 → 许可证”上传文件，也可在 API 容器中执行：

```bash
python -m app.license_cli status
python -m app.license_cli install /path/customer.license
```

许可证绑定页面展示的 `node_id`。部署迁移或显式修改 `NODE_ID` 后，需要重新签发。

## 时间安全

系统记录已见过的最高 UTC 时间。当前时间回拨超过 5 分钟时，付费授权暂停并降级到免费版；修正系统时间后自动恢复。许可证在 `exp` 对应时刻立即到期，不提供额外到期宽限期。
